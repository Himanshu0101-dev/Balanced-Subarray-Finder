# Balanced-Subarray-Finder
Given an array of integers containing only 0s and 1s, find the length of the longest contiguous subarray where the number of 0s and 1s are equal.  Input: An array of integers (only 0 and 1).  Output: The length of the longest balanced subarray.  Constraints:  1 ≤ 𝑛 ≤ 10 5  Array elements are either 0 or 1.
